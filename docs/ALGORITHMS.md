# Pac-Man Search Algorithms

This project implements search techniques for the Berkeley Pac-Man search assignment.

## Implemented algorithms
- Depth-First Search (DFS): explores deeper paths first using a stack.
- Breadth-First Search (BFS): explores paths level by level using a queue.
- Uniform-Cost Search (UCS): prioritizes paths with the lowest cumulative cost.
- A* Search: uses path cost and a heuristic to guide exploration.

## Search problems
- CornersProblem: tracks the corners Pac-Man needs to visit.
- CornersHeuristic: estimates the remaining cost to visit corners.
- FoodHeuristic: estimates the remaining cost to collect food.
- Closest Dot Search: repeatedly finds a path to the nearest food dot.
