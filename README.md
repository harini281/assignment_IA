# Pac-Man Search Algorithms – Intelligent Systems

This repository contains the implementation of classic search algorithms using the Pac-Man search environment.

## Assignment Objective

The objective is to implement uninformed and informed search algorithms and apply heuristic search techniques to structured Pac-Man problems.

## Algorithms

- Depth First Search (DFS)
- Breadth First Search (BFS)
- Uniform Cost Search (UCS)
- A* Search
- Corners Problem
- Corners Heuristic
- Food Search Heuristic
